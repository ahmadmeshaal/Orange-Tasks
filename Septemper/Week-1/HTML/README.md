# HTML Task

## What is this task?

This task focuses on building HTML-only pages without using CSS. The goal is to create three different HTML pages demonstrating fundamental web development concepts:

1. **Form Page** - An HTML form with various input fields and controls
2. **List Page** - An HTML page displaying organized list content
3. **Table Page** - An HTML page featuring tabular data presentation

All implementations use HTML only - no CSS styling is allowed. This helps reinforce understanding of HTML semantics and structure.
