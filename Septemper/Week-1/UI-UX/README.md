# UI/UX Design 🎨

This folder contains the UI/UX tasks completed as part of my **Orange Coding Academy** training.

## 📌 Task Overview

The task focused on designing a modern and user-friendly website interface while applying basic **UI/UX design principles**.

### 🎯 Objectives

* Understand the fundamentals of UI/UX design.
* Create a clear and intuitive user interface.
* Apply visual hierarchy and consistent design principles.
* Design user-friendly layouts and navigation.
* Practice creating wireframes and high-fidelity designs.

### 🛠️ Tools

* Figma
* UI/UX Design Principles

### 📂 Contents

This folder contains the designs and deliverables completed for the task, including:

* Wireframes
* UI Designs
* High-Fidelity Mockups
* Design Screens

### 💡 Key Takeaways

Through this task, I practiced transforming requirements into structured and user-friendly interfaces while focusing on usability, consistency, and visual hierarchy.
