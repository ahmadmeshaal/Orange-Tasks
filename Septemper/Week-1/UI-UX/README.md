Website UI/UX Design Task

Project Context
Assume the role of a junior UI/UX designer at a digital design agency tasked with delivering a client-ready design for a modern project idea. The client requires a clean, user-friendly layout with intuitive navigation and a sleek, contemporary aesthetic. The deliverable spans both structural wireframes and polished mockups for key core pages.

Core Pages Required
•	Page 1: Home / Landing Page (Primary entry point, hero section(the first thing you will see), feature grid, and navigation)
•	Page 2: Primary Feature / Product, service, Details Page (Deep-dive content, key action triggers, and supplementary info)
•	Page 3: Conversion / Checkout / Dashboard Page (User interaction point, transactional or management flow)
Project Requirements & Phases
•	Phase 1: Wireframe Overview
o	Low-fidelity, grayscale layout focusing entirely on structural hierarchy and content placement.
o	Use placeholder boxes for imagery, content blocks, and interactive containers.
o	Exclude color palettes and custom typography during this phase.
o	Include a universal header (logo, search/navigation, profile/cart icons) and footer (minimal links).

•	Phase 2: High-Fidelity Mockup Overview
o	Full-color, interactive preview incorporating the final design system.
o	Include realistic sample imagery, hover states, and functional UI elements.
o	Apply explicit typography scales, color palettes, and styled buttons.
o	Plan for responsive layouts across target screen sizes.
Style Guide Framework
Element Category	Specification Details
Typography	Define Primary Font (Headings) and Secondary Font (Body text) along with explicit pixel scales (e.g., H1, H2, Body).
Color Palette	Establish Primary brand color, Accent/Call-to-Action color, and Neutral Background/Text colors.
UI Components	Specify button shapes (e.g., border-radius, states), icon sets (e.g., Material/ icons), and card containers.
Spacing & Grid	Define standard padding increments (e.g., 8px grid system, 20px card spacing).

Performance & Evaluation Criteria
•	Completeness of Screens (30%): All required core pages are fully built across both wireframe and mockup states.
•	Style Guide Application (20%): Consistent use of designated typography, color codes, and component styling.
•	Layout & Visual Hierarchy (15%): Clear spatial organization, scannable user flows, and effective grid structuring.
•	Wireframe Accuracy (15%): Adherence to low-fidelity structural constraints without premature styling.
•	Mockup Quality & File Structure (20% combined): Polished visual design, proper Figma layer/component organization, and tool proficiency.
